# Command Center acceptance tests

1. Ctrl/Cmd+K opens the palette and focuses the search input.
2. Escape closes the palette.
3. Arrow up/down changes selection and Enter executes the selected command.
4. Query filtering matches labels and keywords.
5. N opens the quick-create menu when focus is not inside a form control.
6. Quick-create entries route to tenant-aware modules.
7. Header exposes command access without removing global entity search.
8. `/command` exposes keyboard shortcuts and command access.
9. Command UI does not expose organization data or bypass API authorization.
