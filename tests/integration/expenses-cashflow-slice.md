# Acceptance tests — Expenses & Cash Flow

- [ ] A submitted expense cannot be paid before approval.
- [ ] An expense can be approved only from SUBMITTED.
- [ ] An expense can be rejected only from SUBMITTED.
- [ ] Paying an approved expense creates exactly one journal entry and one cash transaction.
- [ ] Expense accounting debits net expense + deductible VAT and credits the selected cash account.
- [ ] The same expense cannot be posted twice.
- [ ] Supplier, employee and project references cannot cross organization boundaries.
- [ ] Forecast includes unpaid customer receivables due inside the horizon.
- [ ] Forecast includes unpaid supplier bills due inside the horizon.
- [ ] Forecast includes approved future expenses.
- [ ] Forecast projected balance equals current balance + cumulative incoming - cumulative outgoing.
- [ ] Cross-tenant expense and forecast requests are rejected.
